About Me

I architect agentic AI for cloud operations at Amadeus. My main focus is a self-healing platform: agents that detect, diagnose and fix incidents on a large cloud platform, working alongside humans and deterministic automation.

The hard problems aren't in the models but in the trust around them. How much should an agent do on its own, and how does that autonomy grow as it earns confidence? How do you give an agent exactly the privileges one incident needs, and make sure they don't carry over to the next? I also work on these questions with Amadeus's architecture community on agentic security: sandboxing, agent gateways, and identities for agents.

I came to this through systems: real-time signal processing and early OpenGL, carrier-grade Linux software, mobile devices at HP, identity and API platforms, then Kubernetes, DNS and infrastructure-as-code at enterprise scale. That's why I treat agents as distributed systems that need identities, boundaries and defined failure modes.

Based on the French Riviera. Happy to talk about agentic AI in operations, agent identity and AI governance.

Featured Projects

Self-healing cloud operations with agentic AI

Agents that detect, diagnose and fix incidents on a large cloud platform, alongside humans and deterministic automation. The design adapts IBM's MAPE-K autonomic loop (Monitor, Analyze, Plan, Execute, Knowledge). Agents earn autonomy per subsystem, in four levels: Advisory (the agent proposes, a human acts), Supervised (a human approves), Governed (the agent acts below a risk threshold and escalates above it) and Autonomous (the threshold adapts to context and policy). Remediation agents get privileges scoped to a single incident, so a grant issued for one incident never carries over to the next.

Agentic AI MAPE-K Human-in-the-loop Zero standing privilege
Security patterns for AI agents

Patterns I advocate in my company's architecture community: an inner sandbox for skill and tool execution, an outer sandbox for the agent's OS and network access, an agent gateway as the single enforcement point for every agentic protocol (A2A, MCP, Responses API), and distinct identities for agents acting on their own or on behalf of others.
